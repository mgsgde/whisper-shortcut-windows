# macOS PR #Pilot feedback: safe auto-paste, glossary false inserts, spoken punctuation

Three fixes from a pilot user's feedback (offline Parakeet, direct build, auto-paste on).

**1. Auto-paste never pastes a changed clipboard** (`ae6dcd3b`)
- New pure `ClipboardPasteGuard` (in `PasteTargetPolicy.swift`): paste only if `changeCount` and string still match what we wrote; restore only if `changeCount` did not move.
- Pre-paste delay 50 ms → 150 ms (`AppConstants.autoPastePreDelay`), restore delay 0.4 s → 3.0 s (`AppConstants.clipboardRestoreDelay`), so lazy clipboard readers (browser, Citrix, RDP) get the new text.
- "Transcribe Cancelled Recording" and "Run Again Without Template" run while idle, so they now copy only and never auto-paste into whatever app got the last dictation.
- Tests: `ClipboardPasteGuardTests`.

**2. Glossary boosting no longer inserts unspoken terms** (`f1a1895c`)
- `VocabularyBoostingSession` gets `VocabularyRescorer.Config(spotterRescueMinSimilarity: 0.30, spotterRescueMultiWordMinSimilarity: 0.50)`. With the default floor of 0, "weitere Einschränkungen liegen nicht vor" became "Diarrhöe nicht vor".
- Live test `glossaryTermNotInserted` gated by `WHISPERSHORTCUT_BENCH_PARAKEET=1` (not run in CI).

**3. Spoken punctuation** (`fd3ca3fd`, `e6bd303b`)
- "Schrägstrich" → "/" for offline models.
- New setting Settings → Dictate → Punctuation: Automatic (default, unchanged) / Only when spoken. Spoken-only strips the model's `. , ; ! ?` (only before whitespace/end, so numbers survive), maps Punkt/Komma/Fragezeichen/Ausrufezeichen, and skips the trailing period. Meetings keep automatic punctuation. Shown only for offline models.
- Known edge: in spoken-only, "drei Komma fünf" becomes "drei, fünf".

**Tests** (`bash scripts/run-tests.sh`): `✘ Test run with 1253 tests in 156 suites failed after 9.428 seconds with 3 issues.` The 3 are the live-API tests with `.incorrectAPIKey` (DictatePromptAgentTests:111, TranscriptionRoundtripTests:92, WhisperShortcutTests:24), no key in the test env.

Build variants: auto-paste and the menu re-runs are direct build only; punctuation and glossary apply to both.
